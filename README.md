# Exam App — Exam Management System

A modern and responsive Exam Management System built with React, TypeScript, and Tailwind CSS. The application provides an admin dashboard for managing diplomas, exams, questions, and audit logs.

## Features

- **Authentication** — Login and role-based access control.
- **Diploma Management** — Create, update, and manage diplomas.
- **Exam Management** — Create and manage exams linked to diplomas.
- **Question Management** — Create and update questions with multiple answers and correct-answer validation.
- **Search and Filtering** — Find exams and diplomas using search and filters.
- **Sorting and Pagination** — Navigate and organize data efficiently.
- **Audit Logs** — View activity records and log details.
- **Responsive UI** — Layout designed for desktop and mobile screens.
- **Form Validation** — Validate user input with React Hook Form and Zod.
- **Reusable Components** — Maintainable UI components and a structured project architecture.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/abdelhamed59/Exam-App
   ```

2. Navigate to the project directory:

   ```bash
   cd exam-app
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
